Five things it is actually good at.

It reads the web for you

It turns a topic into several searches, reads up to six pages at once, and writes an answer where every claim carries a numbered citation you can check. Plain HTTP first because it is fast, and a real Chromium only when a page is JavaScript-only or wants clicking.

  • research the best budget monitors
  • summarise this link
  • get all the links from that page
2.7s

to walk 48,787 files into a graph of folders and files. Ask it anything about your own machine afterwards.

It grows as you use it

Ask for something it has no skill for and it works it out the long way, writing and running code as it goes. Then it turns that work into a tool of its own, runs the tool on the same question, and keeps it only if it gives the same answer. Next time, a request like that skips straight to the tool. A tool that keeps failing is retired.

  • make a tool that counts lines of code in a folder
  • what tools have you made
  • forget the tool count_python_lines
11.6s → 0.7s

the same kind of question, the first time and the second. Measured on a request it had never seen before.

It knows your PC

Where that file went, what is eating your disk, what you touched today, what is in a folder without opening it.

  • where did i put my resume
  • what's eating my disk space
  • what did i work on today

It writes and runs things

Create folders, write and edit files, close a program that is hogging the CPU, keep your to-do list. It never touches Windows or Program Files, never overwrites without being asked, and deleting goes to the Recycle Bin.

  • add a line to notes.txt saying call mum
  • kill chrome
  • remind me to call the dentist tomorrow

How a request runs.

you type it Ask

Type it in the panel, however you would say it out loud. Voice is coming, once it can be set up in one click and answer back.

under a millisecond Match

Hashed word and character n-grams score your sentence against every skill. No model to download, no embedding server, no wait.

your call, and you can watch it Run

Manual mode shows the match and its confidence first; auto mode just runs it. Either way you see each step as it happens, and a clock, so nothing ever looks stuck. Anything irreversible asks first.

The brain is NVIDIA's free API: paste a free key on first run and it uses a 550B model, no graphics card needed. And it grows. Ask for something new and it works it out the long way, then writes itself a tool, tests it against the answer it just gave, and keeps it. Next time a request like that is one quick step: 11.6 seconds the first time, 0.7 after.

one question It answers

Not a wall of scraped page. Six sources, read in parallel and turned into a short answer with a numbered citation on every claim.

two verbs It plans

"Find the best monitors and open the top result" becomes two steps you can see before either of them runs.

no pretending It admits

Ask it to apply for jobs and it says plainly: it can find and open the pages, but signing in and filling the form is yours.

Download it, double click it, done.

Download for Windows Portable zip

29MB installer. No admin rights needed, and the setup asks whether you want it to start when you sign in. On first run it asks for a free API key from build.nvidia.com: paste it once and it is saved on your PC only. Nothing to download, no graphics card needed.

Your buddy appears in the bottom right of the screen. Click it to open the panel, drag it wherever you like, right click it for settings.

Or run it from source, on any OS

# Windows, macOS or Linux. Python 3.10+
git clone https://github.com/SahilSidhu7/VirtualBuddy
cd VirtualBuddy
pip install -r requirements.txt
python run.py

Prefer a terminal? python run.py --cli.

It shows its work. Reading four sources takes a few seconds, so it tells you which one it is on and how long it has been going. No spinner that could mean anything.
The browser tier is lazy. Chromium is only downloaded the first time a page genuinely needs it, so a plain install stays small.
Your data stays put. The file index, your settings, your to-do list and the tools it writes for itself live in ~/.virtualbuddy, in formats you can open yourself. Uninstalling leaves them alone.
What goes to NVIDIA. Your questions, and what the buddy needs to answer them, are sent to NVIDIA's API. Your files are read and run on your own PC, and a screenshot is only sent when you ask it to look at your screen.
Starts with Windows, if you want. Tick the box during setup, or turn it on and off any time by right clicking your buddy. It is a shortcut in your Startup folder, nothing hidden in the registry.
