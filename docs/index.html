Windows
macOS
Linux

First run downloads a small brain model into RAM (once), then it's fast. Add --voice to set up offline speech.

How your machines link

Everything talks over your own WiFi. No cloud, no accounts.

The host runs a tiny token-protected HTTP server. Your phone opens its URL on the same WiFi; other PCs running buddy are added as "peers" so you can say on pc2 lock the screen and it runs there.

Getting started
  1. Install (above).
  2. python app.py opens the control panel.
  3. Set your model + wake word, pick a character.
  4. python run.py --character to put buddy on screen.
Make a skill

A skill is one Python file with a SKILLS list:

SKILLS = [{
  "name": "greet",
  "desc": "say hello",
  "phrases": ["say hi", "greet me"],
  "run": lambda text, ctx: "Hey there!",
}]

Drop it in buddy/skills/, run !train. Full template in the skills repo.

Set up phone + PC↔PC sync

python run.py --server (or the Sync tab). It prints a URL like http://192.168.1.20:8770. Open it on your phone (same WiFi), enter the token from config.yaml. For another PC, add it under peers.

Save Claude tokens

Order buddy tries: matched skill → local LLM → free web search → Claude (last). Flip on power-saving to drop the LLM and free RAM entirely.
